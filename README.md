## 🧵 Threads & Co. — E-Commerce Web App

**Threads & Co.** is a full-stack e-commerce web application built with **Django** for a modern fashion store.
It features a clean UI, robust backend logic, and a complete shopping workflow — from product catalog to checkout and order management.
Originally developed in 2023, this version was **revamped using Django** for better scalability, data integrity, and maintainability.

### 🩵 Key Features

* **Dynamic Product Catalog** — Products loaded directly from the database with responsive grid design.
* **Shopping Cart System** — Quantity updates, duplicate prevention, and session-based persistence.
* **Checkout & Order Confirmation** — Customer details captured and stored with unique order grouping.
* **Admin Dashboard** — Manage products, customers, and orders with CRUD functionality.
* **Responsive Design** — Built with HTML, CSS, and JavaScript for a modern, mobile-friendly UI.

### 🧩 Tech Stack

| Layer            | Technology                     |
| ---------------- | ------------------------------ |
| **Backend**      | Django 5.0 (Python)            |
| **Frontend**     | HTML5, CSS3, JavaScript (ES6+) |
| **Database**     | SQLite3                        |
| **Architecture** | MVC (Model–View–Template)      |

### 🚀 How to Run Locally

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```

Then open: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
